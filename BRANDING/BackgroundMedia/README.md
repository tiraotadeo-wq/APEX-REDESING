# MOONX7 BackgroundMedia

Coloca aquí tu fondo animado.

Archivos soportados:
- background.mp4
- background.mov
- background.m4v
- background.gif
- background.png / background.jpg / background.jpeg

La app prioriza cualquier archivo llamado `background.*`. Si no existe, toma el primer archivo compatible.
Los vídeos se reproducen en silencio, en bucle y con aspectFill.
Los GIF se decodifican en segundo plano, con cache y reducción de tamaño.
